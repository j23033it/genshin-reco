# UIミニ契約

## 目的

4人編成の入力から、分析の進行状況、条件へ適合する候補、根拠品質、代替候補、ユーザー選択が必要な差分を日本語で追跡できること。

## 構成

- 広幅: 左に編成一覧、中央に編成編集と比較、右に分析結果と根拠。
- 狭幅・200%ズーム: 左ペインをDrawer化し、編集と結果をタブで切り替える。
- 4人比較は列を削除せず、狭幅ではカードまたは横スクロールへ切り替える。

## 状態

- 下書き、未分析、分析中、成功、失敗、キャンセル、要再確認。
- 分析中も最後の成功結果を残し、古い結果であることを明示する。
- 進捗は割合ではなく、キャラクター別・工程別の状態を表示する。
- 空状態には次の操作を1つ示す。
- エラーは発生した操作の近くに表示し、回復操作を示す。

## アクセシビリティ

- ネイティブ要素とBase UIを優先する。
- キーボードだけで編成編集、保存、分析、選択、キャンセルを完了できる。
- アイコンのみのボタンには日本語の`aria-label`を付ける。
- ダイアログを閉じた後は起点へフォーカスを戻す。
- 状態は色だけで表さず、テキストと属性を同期する。
- 処理状態はライブリージョンで通知する。
- 見出しには`text-balance`、本文には`text-pretty`、数値には`tabular-nums`を使う。

## 視覚方針

- 1画面のアクセント色は琥珀色1色を基本とする。
- グラデーションと主役としてのグローは使わない。
- 明示要求がない限りアニメーションを追加しない。
- Tailwindの既定値と固定z-indexスケールを使う。

## 検証

- lint、typecheck、build、unit/component test。
- キーボード、フォーカス、loading/empty/error/success、二重実行防止。
- 960px以上の3ペイン、狭幅、長文、200%ズーム、overflow。
- 自動a11y検査と読み上げ順の手動確認。
