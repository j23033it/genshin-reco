# 編成作成・分析結果 UI 改修原稿

更新日: 2026-08-31

## 1. 目的

編成画面を、新規作成、保存済み編成の編集、分析開始、分析結果の確認までを一続きで扱う作業場所にする。独立した「分析結果」画面は廃止し、保存済み編成の選択を入口にする。

分析結果は、4人分の推奨内容を横スクロールなしで比較できる、短く視覚的なまとめへ作り替える。添付画像からは、2×2の情報配置、アイコンと名称の併記、武器・聖遺物・ステータスの短い行表現だけを参考にし、装飾や立ち回り欄は取り込まない。

## 2. 画面の責務

### 編成を作る

- 左ナビゲーションの「編成を作る」は、未入力の新規編成を開く。
- 編成名、4人のキャラクター、武器、命ノ星座、精錬ランクを入力できる。
- 保存だけを行うボタンは置かない。
- 「分析を開始」は入力を一時保存して分析へ渡す。分析に成功した時だけ、保存した編成の一覧へ追加する。
- 新規編成の分析に成功したら、作成フォームの編成名と4人分の入力を空の新規状態へ戻す。
- 分析に失敗またはキャンセルした新規編成は一覧へ追加せず、再試行できるよう入力を残す。

### 保存した編成の詳細

- アプリ起動時は、最後に更新された保存編成の編集内容と現在結果を表示する。
- 保存した編成をクリックした時は、対象編成の入力内容と分析結果を同じ中央ページへ読み込む。
- 入力内容を変更して「分析を更新」を押すと、変更後の内容を保存して再分析する。
- 再分析中も直前の成功結果は古い結果として保持し、完了後に最新結果へ差し替える。
- 対象編成に分析結果がない場合は、再分析できる編集フォームと空状態を表示する。
- 結果の候補選択は、表示中の分析結果に紐づく編成IDへ保存する。
- 「編成を削除」は確認ダイアログを開き、確定後に一覧と通常の読み込み対象から除外する。検証済み分析履歴は不変データとして保持する。

### 保存した編成

- これまで保存した編成を更新日時の新しい順で並べる。
- 選択中の編成を見た目と `aria-current` で示す。
- クリックすると同じ編成画面で、編集フォームと現在結果を読み込む。
- 各編成には削除操作を置き、編成名を含む確認ダイアログで誤操作を防ぐ。
- 編成検索と「新しい編成を作成」は残す。

### 左サイドバー

- 主要画面は「編成を作る」と「Codex設定」の2つだけとし、「分析結果」は置かない。
- 開閉ボタンでサイドバー全体を隠せる。閉じた状態でも同じ場所から再度開ける。
- 開閉ボタンは `aria-expanded` と `aria-controls` で状態を通知し、アイコンだけの場合は日本語の `aria-label` を付ける。

## 3. 分析結果カード

1280px以上の広幅では4人を2×2グリッドで表示する。各カードは横幅を画面内へ収め、ページ内に横スクロール領域を作らない。それ未満の幅では1列へ折り返す。

各キャラクターカードに表示する内容:

1. スロット番号、キャラクターアイコン、日本語のキャラクター名、命ノ星座
2. 武器アイコン、日本語の武器名、精錬ランク
3. 聖遺物の代表アイコンと日本語名称
   - 4セット指定では「4セット」という接尾辞を表示せず、セット名だけを表示する。
   - 2セット＋2セットでは、それぞれのセット名または同効果セット群の日本語説明を表示する。
   - 生のセットID・効果グループIDは表示しない。
4. メインステータス: 砂・杯・冠を1つの短い行として表示する。
5. 優先サブステータス: 優先順を `>` で結んだ短い行として表示する。
6. 目標ステータス: 名称と目標値を簡潔に並べる。

### 目標ステータスの算出契約

- 目標値は外部ページの数値をそのまま転載せず、現在の4人編成、装備武器、精錬ランク、命ノ星座、聖遺物効果、キャラクターの天賦・固有天賦、元素共鳴を考慮して算出する。
- 各候補には、役割に応じた火力・反応・元素エネルギーの主要ステータスを最低2種類表示する。
- 会心率は戦闘中に適用可能な会心率加算を合算し、実効会心率が100%を超えない戦闘前上限を逆算する。氷共鳴、聖遺物セット、武器効果、天賦、命ノ星座など、条件付き効果も成立条件とともに計算へ含める。
- 攻撃力・HP・防御力・元素熟知などの主要参照ステータス、会心率、会心ダメージ、ダメージバフを一種類へ偏らせず、期待火力が伸びる均衡した範囲を提示する。元素反応主体など会心を利用しないビルドでは、その理由を計算メモへ残して別の有効ステータスを優先する。
- 元素チャージ効率は、推奨ローテーションで元素爆発を安定して使用するための下限として扱い、必要以上に火力ステータスを削らない範囲にする。
- 各目標値には数値の下限または上限と、含めた効果・条件・逆算内容を短い計算メモとして保存する。会心率へ加算する効果は名称・加算量・条件を構造化して保存し、戦闘前上限との合計が100%以下であることをアプリ側でも検証する。計算メモと加算内訳は主要カードではなく右の補足欄へ表示する。
- 目標値、またはその計算を支える本文確認済みの根拠が不足する分析結果は成功扱いにしない。
- この契約より前に保存された目標値なしの結果は自動補完せず、「未算出（再分析が必要）」と表示する。

カードから削除する内容:

- 推薦理由
- 根拠、EvidenceGrade、verification、引用、出典要約
- 生の英語enum・ID
- 立ち回り
- 内容より大きい横長のテキスト枠や表

候補選択が必要な場合は、選択ボタンをカード内に表示する。確定済みの別候補は既定で折りたたみ、4人の主要情報を邪魔しない。

## 4. 補足事項

分析結果画面の右ペインを補足欄として使う。

- チーム全体の警告
- 目標値の注記
- 適用条件
- 古い結果・無効な結果の注意

補足がない場合は「補足事項はありません」と表示する。推薦理由や根拠の代替欄にはしない。

編成作成画面とCodex設定画面では、従来どおりカタログ、更新日、保存件数などのデータ状態を表示する。

## 5. 状態と操作

- `loading`: 保存編成と分析結果の読み込み中であることを表示し、多重読み込みによる古い応答の上書きを防ぐ。
- `empty`: 最後の分析結果がない場合は、編成作成への次操作を1つ案内する。
- `success`: 表示中の編成名と4人分の結果を表示する。
- `needs_user_choice`: 候補をキーボードで選択できる。
- `failed`: 発生した操作の近くにエラーと回復方法を表示する。
- `stale / invalid`: 色だけでなく文言でも状態を伝え、右の補足欄にも表示する。
- 分析していない通常時は「調査中」「調査完了」などの工程表示を出さない。
- 分析中は、その分析対象の編成ページ内だけに進捗を表示する。他の保存編成へ移動した場合は表示しない。
- 分析中の進捗は4人のキャラクターアイコン、短いキャラクター名、現在工程だけの小型表示とする。完了後は進捗表示を消す。
- 分析中も最後の成功結果は消さず、古い結果であることを明示する。

## 6. レスポンシブとアクセシビリティ

- 1024px以上は、左にナビゲーション、中央に作成または分析結果、右にデータ状態または補足事項を置く。
- 中央の4人比較に `overflow-x-auto` や固定最小横幅を使わない。
- 狭幅では画面全体の通常フローで縦に並べる。情報や列を削除しない。
- 200%ズーム、長い日本語名、空データでも横方向にはみ出さない。
- 保存編成、候補選択、画面移動はネイティブの `button` で操作できる。
- 編成削除はBase UIのAlertDialogを使い、初期フォーカス、Escape、閉じた後のフォーカス復帰を委ねる。
- キーボードフォーカスを視認でき、選択中・処理中・エラーを属性とテキストで通知する。
- 画像には内容が分かる日本語の代替テキストを付ける。
- 見出しには `text-balance`、本文には `text-pretty`、数値には `tabular-nums` を使う。

## 7. 視覚方針

- 既存のダークテーマと琥珀色アクセントを維持する。
- グラデーション、主役としてのグロー、新規アニメーションは追加しない。
- 既存のTailwindトークン、`cn`、Base UI方針を維持する。
- 情報は枠で囲み続けず、見出し、余白、短い区切り線で階層化する。
- キャラクター、武器、聖遺物の画像を名称の補助として使い、画像だけで意味を伝えない。

## 8. 受け入れ条件

- 新規編成には保存ボタンがなく、分析成功時だけ保存編成一覧へ追加される。
- 新規編成の分析成功後は、作成フォームが空の新規状態へ戻る。
- 分析失敗・キャンセル時は新規編成が一覧へ追加されず、入力を保持して再試行できる。
- 保存編成を押すと、その編成の入力内容と分析結果が同じ中央ページに表示される。
- 保存編成の内容を変更して分析を更新できる。
- 保存編成を確認ダイアログ経由で削除でき、削除後は一覧と通常読み込みから消える。
- 左ナビゲーションに「分析結果」がなく、サイドバーを開閉できる。
- 通常時はキャラクター別工程を表示せず、分析中の対象編成だけに小型のアイコン進捗を表示する。
- 再起動後、最後に更新された保存編成と分析結果が初期表示される。
- 分析結果にキャラクター名・アイコン、武器名・アイコン・精錬、聖遺物名・画像が表示される。
- 新しい分析結果では各キャラクターに2種類以上の数値付き目標ステータスが表示され、会心率には戦闘中の加算を考慮した100%以下の上限と計算メモがある。
- 分析結果に理由、根拠、生のID、「4セット」、立ち回りが表示されない。
- 4人分の主要情報がデスクトップで2×2に収まり、中央コンテンツに横スクロールが発生しない。
- 補足事項が右ペインへまとまり、主要カード内の目標値は簡潔に保たれる。
- lint、型検査、unit/component test、build、Rust testが通る。
- 実ブラウザで代表的なデスクトップ幅、狭幅、200%ズーム相当を確認し、重なりとはみ出しがない。
