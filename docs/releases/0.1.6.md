# ビルドレコメンダー 0.1.6

- アプリの表示名を「ビルドレコメンダー」に更新しました。
- 武器・光円錐を名前で検索できるようにし、キャラクターの武器種・運命に合う候補を表示します。
- 新しい編成の調査結果を取り込む際、武器名の精錬表記や結果の並び順によって、正しい指定条件が不一致として扱われる問題を修正しました。
- 指定したキャラクター・凸・武器・精錬を守り、指定なしの項目は編成に合わせて提案します。別のキャラクターや武器への変更は引き続き検出します。
- 条件の整理と調査の同時実行を防ぎ、原神と崩壊：スターレイルの保存結果の検証を改善しました。

既存アプリの識別子・保存先・更新先・署名用公開鍵を維持します。セットアップ画面と既定インストールフォルダーには、互換性のため旧名が残ります。
