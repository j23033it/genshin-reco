# ビルドレコメンダー 0.1.7

- 崩壊：スターレイルの名称・分類カタログを、2026-10-04時点の正式公開版4.6まで更新しました。93キャラクター形態・170光円錐・34トンネル遺物・28オーナメントを選択できます。
- 愉悦の運命と開拓者の新形態に対応しました。新しいキャラクター・光円錐・遺物を指定して編成を調査できます。
- 既存のカタログID・名称と保存データを維持します。実在対象を特定できない旧名称「瞬間を記憶に留めて」「悠久の地アムフォレウス」は、保存済みの表示と編成名変更で保持します。再調査時には有効な装備を選び直すか「指定なし」に戻してください。

同梱データは名称と分類の一覧です。性能・効果・ビルドの根拠は調査時に本文を確認します。原神のカタログ、既存アプリの識別子・保存先・更新先・署名用公開鍵を維持します。
